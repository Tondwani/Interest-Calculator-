Interest Calculator - Simple and Advanced
This project is an interactive web-based interest calculator that allows users to calculate both simple and advanced (compound) interest. The calculator includes features for entering principal amounts, selecting interest rates, and choosing the number of years. It also provides options to compute compound interest with different compounding frequencies. The results can be displayed directly on the page or downloaded as a PDF.

Features
Simple Interest Calculator
Amount: User inputs the principal amount.
Interest Rate: A slider is provided to adjust the interest rate (from 1% to 20%).
Number of Years: A dropdown allows users to select the number of years (1, 5, 10, 15, or 20).
Compute: A button that computes the simple interest based on the entered values.
Advanced Interest Calculator
Principal Amount: User inputs the principal amount.
Interest Rate: A slider to adjust the interest rate (from 1% to 20%).
Number of Years: A dropdown allows users to select the number of years (1, 5, 10, 15, or 20).
Compounding Frequency: Options to choose how often interest is compounded (Annually, Semi-Annually, Quarterly, Monthly).
Compute: A button to compute the compound interest based on the input values.
Download Results: A button to download the results in a PDF format.
Technologies Used
HTML: For structuring the content and creating forms for user input.
CSS: For styling and enhancing the visual design of the application.
JavaScript: For performing the calculations and interactivity (e.g., updating slider values, computing interest, and generating PDFs).
Chart.js: For potential future data visualizations (not currently implemented but planned).
jsPDF: For generating downloadable PDFs with results.

How to Use
Open the webpage in your browser.
For Simple Interest Calculation, enter the principal amount, adjust the interest rate using the slider, and select the number of years.
Click the "Compute Simple Interest" button to get the result.
For Advanced Interest Calculation, input the principal, adjust the interest rate slider, select the number of years, and choose the compounding frequency.
Click the "Compute Compound Interest" button to get the result.
Optionally, click the "Download Results" button to download the interest calculation as a PDF.
